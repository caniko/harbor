# Harbor

Shared build, toolchain, and integration infrastructure for Caniko projects.

This checkout is the history-preserving consolidation of the Harbor repositories.
Imported Git commits retain their original authors and object identities. Source
revisions and source-prefix mappings are recorded in `migration/sources.json`.

Components retain their package names, licenses, and independent release versions.
The initial `sources/` prefixes preserve the source trees while shared workspace,
Nix, and release integration is qualified.
